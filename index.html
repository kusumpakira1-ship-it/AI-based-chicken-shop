2. Connecting Physical Weight Scale

  • Option A (Browser Web Serial API): Click "Connect Physical Scale" at the top header to pair directly with USB-to-Serial scale controllers (9600 baud rate).
  • Option B (Microcontroller ESP32 + HX711 Load Cell): ESP32 sends weight readings via WebSocket to `ws://localhost:8080/scale`.

3. Camera AI Training & Real-time Edge Model

  • Train YOLOv8 or MobileNetV3 image classification dataset with photos of:
    • Goat Meat (Mutton curry cuts, chops)
    • Chicken Meat (Whole chicken, skinless, bone-in)
    • Fish (Rohu, Katla, Pomfret, Kingfish fillets)
    • Prawns & Seafood
  • Deploy model on local FastAPI Python server with GPU / NPU acceleration.
